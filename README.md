The winning word: **"unavailable"** — the one word every ex reaches for: emotionally, physically, or just permanently "busy". It stings because it is true, it lands instantly, and everyone has either said it or heard it. The program scores a small table of candidate single words an ex would use on ex-voice, funniness, sting, instantness and relatability, picks the best one, checks it against the competition's gate (exactly one word, 1–24 characters), and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
